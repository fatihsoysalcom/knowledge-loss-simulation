# Knowledge Loss Simulation

This Python script simulates the impact of knowledge loss in a company due to over-reliance on human memory versus documented knowledge. It demonstrates how individual departures can drastically reduce a company's knowledge base when information is not systematically captured.

## Language

`python`

## How to Run

Save the code as `knowledge_loss.py` and run it from your terminal using: `python knowledge_loss.py`
